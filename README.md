# la-mesa-larga
App de juegos de mesa

## Norma de versiones (`APPV` en `index.html`)

Formato **aa.bb.cc**, siempre con dos cifras como mínimo:

- **aa**: actualización muy grande. Se reserva para cuando la app se presente como finalizada (aún no se ha llegado).
- **bb**: actualización media, por ejemplo cuando se añade un juego completo nuevo.
- **cc**: actualización menor, la habitual (ajustes, mejoras, correcciones).

Al subir `aa` se ponen `bb` y `cc` a 00; al subir `bb` se pone `cc` a 00.
Cada publicación debe subir la versión (`APPV`) y actualizar `APPN`, porque las actualizaciones son obligatorias.
La versión **00.01.00** es la primera con este formato; todo lo anterior (1–172) cuenta como la primera versión media.
